## NonNull Api
- Spring 6까지 java 에서 취약한 null check 를 위해 @NonNull 등 애노테이션을 채용하여 컴파일 시점의 null-safety 를 올리려는 노력이 있었음.
- com.github.spotbugs plugin 을 이용하면 컴파일 시점에 해당 null check 를 사전에 할 수 있음
- Spring 7 부터는 `JSpecify` 라는 벤더의 애노테이션으로 많이 변경됐음
