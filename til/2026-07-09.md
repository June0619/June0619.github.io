## Splearn
- 도메인 모델 패턴의 두가지 스타일
    - 단순 도메인 모델 (Simple Domain Model): DB 설계와 유사한 도메인 모델
    - 풍성한 도메인 모델 (Rich Domain Model): 상속이나 전략, GoF 디자인 패턴, 연관 관계

- 도메인 로직의 API 개발
    - 트랜잭션 스크립트처럼 작업 단위 절차형 API를 만들기 어렵다.
    - 도메인 로직의 명확한 작업 단위 API를 제공하는 애플리케이션 서비스가 필요
        - 도메인 로직이 애플리케이션 서비스를 제공하도록 하는 계층을 Domain Facade 라고도 한다.
