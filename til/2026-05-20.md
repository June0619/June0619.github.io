## Rate Limit
- 특정 시스템 부하를 막기 위해 특정 API KEY나 end-point 단위로 시간당 트래픽을 제어하는 것
    - 예: `/mail-send` API 로 들어오는 요청을 분당 10개로 제한하는 등

## Bulk Head
- Rate Limit 과 컨셉은 비슷하지만 방법에 차이가 있음. 특정 기능단위로 인입되는 물리적 스레드 숫자를 제한함.
    - 대표적으로 Tomcat Thread pool 혹은 DB Connection Pool 등이 Bulk Head 사용예시


## 기타 장애를 줄이기 위한 노-력

### 관측 가능성 (Observability)
- 로그, 메트릭 등 시스템 전반의 투명도

### 테스트에 대해
- 비즈니스적 테스트
    - 단위테스트
    - 통합테스트
    - E2E 테스트
- 시스템 테스트
    - 서킷이 잘 열리는지
    - Retry, Fallback 이 잘 동작하는지
    - 카오스 엔지니어링 테스트 등

### 배포 전략
- 얼마나 빠르고 안전하게 복구나 모니터링이 가능한지

## SPOF (Single Point of Failure)
- 단일 장애점: 분산 환경에서 장애를 유발하는 단일 장애점을 의미함
